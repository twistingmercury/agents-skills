# Working style

- **Simplicity above all.** No variables for values that never change, no checks for things that must exist, no commands or abstractions for needs that have not appeared. Fail fast.
- **Verify before asking or claiming.** Read the code and docs first; ask only for decisions that are the owner's.
- **Deferred findings go to GitHub issues.** Register bugs and deferred items in the project's tracker (`gh issue create`) instead of leaving them in notes. No secrets in the issue; mark unverified claims as unverified.
